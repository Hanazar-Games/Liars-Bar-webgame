# 骗子酒馆 · Liar's Table

一款可直接在浏览器游玩的单人吹牛卡牌游戏。你将与三名 AI 玩家交替暗扣出牌，声称打出的都是当局指定牌；识破谎言，或承担质疑失败的后果。

## 玩法

- 每轮指定 A、K 或 Q 中的一种牌，JOKER 可以代替任意指定牌。
- 选择 1–3 张牌暗扣出牌，所有人都必须声称自己出的是指定牌。
- 可以继续出牌，也可质疑上家。质疑成功由撒谎者扣动左轮，失败则由质疑者受罚。
- 最后一名存活的玩家胜利。

## 运行

项目无构建依赖，可直接打开 `index.html`，或启动一个本地静态服务器：

```bash
python3 -m http.server 4173
```

然后访问 <http://localhost:4173>。
