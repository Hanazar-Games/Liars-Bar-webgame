# 骗子酒馆 · Liar's Table

一款支持单人 AI 与局域网 2–4 人联机的吹牛卡牌游戏。玩家轮流暗扣 1–3 张牌，所有人都必须声称打出的是本局指定牌；质疑失败或谎言败露的人需要扣动左轮，最后存活者获胜。

## 功能

- 单人模式：与三名 AI 玩家完整对局。
- 局域网模式：房间码、2–4 人实时同步、房主开局和原房间重赛。
- 服务端权威规则：其他玩家的手牌不会发送到你的浏览器。
- 断线处理：失联玩家自动离席，房主断线后自动转移。
- 自适应界面：桌面、手机、横屏和安全区域布局。
- 声音体验：程序生成的分层操作音效、左轮反馈和动态酒馆环境氛围。
- 个性设置：分别控制总音量、音乐、音效、动画与桌面光影。
- 多语言与教程：10 种核心界面语言和四步交互式新手引导。
- 酒客档案：记录本场行为、声名倾向与动态称号，不保存跨会话数据。
- 无障碍支持：原生隐藏、模态焦点循环、状态播报和减少动画设置。

## 运行

需要 Node.js 18 或更高版本。

```bash
npm install
npm start
```

服务启动后会输出本机地址和局域网地址，例如：

```text
http://localhost:4173
http://192.168.1.20:4173
```

本机使用第一个地址。同一 Wi-Fi/局域网内的其他玩家使用第二个地址。进入“局域网联机”后，由一名玩家创建房间并分享四位房间码。

由于浏览器模块和 WebSocket 需要 HTTP 服务，不再支持直接双击 `index.html` 运行完整游戏。

## 测试

```bash
npm test
```

测试覆盖牌组、发牌保密、回合权限、出牌校验、质疑、左轮淘汰、断线离席，以及两个真实 WebSocket 客户端的创建房间、加入、开局、同步和重赛流程。

## 联机边界

- 房间与牌局仅保存在服务器内存中，服务器重启后清空。
- 当前版本不包含账号、密码、公网匹配、跨服务重连或局域网自动发现。
- 房间码用于快速加入，不是安全凭证；只应在可信局域网内使用。
- 默认监听 `0.0.0.0:4173`，可用 `HOST` 和 `PORT` 环境变量修改。
